## Objective
Create two NumPy arrays and perform addition, subtraction, multiplication, and division. Check array shapes and understand vectorized operations.

## Technologies Used
- Python
- NumPy
- Jupyter Notebook

## Operations Performed
- Created two NumPy arrays.
- Checked array shapes using `.shape`.
- Performed addition, subtraction, multiplication, and division.
- Used vectorized operations to calculate results element by element.

